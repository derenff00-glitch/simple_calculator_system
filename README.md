Software Development Life Cycle (SDLC)
1. Requirement Analysis

The requirement is to develop a simple calculator application using Python that can perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

2. Design

The application is designed as a menu-driven, console-based program. It uses a loop for continuous execution and conditional statements to perform selected operations.

3. Development

The calculator is developed using Python programming language. Arithmetic operations are implemented using simple operators.

4. Testing

The program is tested with different inputs including valid numbers, invalid inputs, and division by zero to ensure correct functionality.

5. Deployment

The application is executed in the Python environment and made available for user interaction through the terminal.

6. Maintenance

Future updates may include adding more mathematical operations and developing a graphical user interface.
